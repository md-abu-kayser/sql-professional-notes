# SQL Professional Notes

A structured, from-fundamentals-to-advanced collection of SQL notes covering relational
database concepts, query writing, optimization, schema design, security, and
database-specific implementations (PostgreSQL, MySQL, SQLite, SQL Server, Oracle).

## How this repo is organized

| Folder | Covers |
|---|---|
| `00-prerequisites/` | Setting up a database, clients/IDEs, CLI basics |
| `01-fundamentals/` | Core SQL syntax, SELECT/INSERT basics |
| `02-data-manipulation/` | UPDATE, DELETE, aliases, computed columns |
| `03-filtering-and-operators/` | WHERE clauses, pattern matching, operators |
| `04-functions-and-aggregations/` | Aggregate functions, GROUP BY, string/date/math functions |
| `05-joins/` | INNER/OUTER/CROSS/SELF joins, join algorithms |
| `06-subqueries-and-set-operations/` | Subqueries, CTEs, UNION/INTERSECT/EXCEPT |
| `07-views/` | Views, materialized views |
| `08-transactions-and-concurrency/` | ACID, isolation levels, locking, MVCC |
| `09-indexing/` | Index types, composite/partial/covering indexes |
| `10-query-optimization/` | EXPLAIN, cost estimation, query tuning |
| `11-schema-design-and-data-modeling/` | Normalization, keys, ERDs |
| `12-stored-procedures-and-functions/` | Procedures, functions, triggers, cursors |
| `13-security-and-user-management/` | Roles, privileges, RLS, SQL injection |
| `14-window-functions/` | OVER/PARTITION BY, ranking, running totals |
| `15-recursive-queries-and-hierarchical-data/` | Recursive CTEs, trees, graphs |
| `16-advanced-sql-techniques/` | LATERAL joins, PIVOT, JSON/XML, full-text search |
| `17-database-specific-implementations/` | PostgreSQL, MySQL, SQLite, SQL Server, Oracle specifics |
| `18-tools-and-workflow/` | Migrations, schema version control, linting |
| `19-testing/` | Unit/integration/load testing for SQL |
| `20-real-world-projects/` | End-to-end schema + query examples (e-commerce, social, SaaS, analytics, IoT) |
| `21-code-snippets/` | Ready-to-use `.sql` snippets |
| `22-resources-cheatsheets/` | Cheatsheets, comparisons, interview prep, further reading |

## Status

This is a scaffold: every note file includes a consistent template (Overview, Key
Points, Example, Common Pitfalls, Related Topics, References) ready to be filled in
as you work through the material.
